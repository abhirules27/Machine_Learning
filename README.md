# ML-Proj-1-Logistic_Regression
Student Placement Prediction (Logistic Regression) - This mini project uses Logistic Regression to predict whether a student will be placed (Yes/No) based on two features: CGPA and IQ. It’s simple, fast, and interpretable—perfect for small, linearly separable datasets. Model: Scikit-learn LogisticRegression (with feature scaling)
